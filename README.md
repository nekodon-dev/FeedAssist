# Feed Assist

Fabric / Minecraft 26.1.2 / Java 25

## 導入
配布用の feed-assist-mc26.1.2-1.0.0.jar と Fabric API を mods フォルダに入れてください。
Fabric Loader 0.19.3 以降が必要です。設定画面を使う場合は Mod Menu 18.0.0 も導入してください（任意）。
シングルプレイではクライアントに、マルチプレイではサーバーに導入します。
サーバー側だけでも動作します。クライアント側だけに入れても、未導入の外部サーバーでは範囲餌やりできません。

## 使い方
- 繁殖用の餌を持って、繁殖可能な大人の動物を右クリックします。
- クリックした動物が繁殖モードになると、プレイヤーから半径10ブロック以内の動物にも、近い順に同じ餌を与えます。
- 餌に対応する種類が対象です。例：小麦なら牛・羊、ニンジンなら豚。
- 使用した手のスタックだけを使い、餌がなくなると終了します。オフハンドにも対応します。
- 餌の消費や効果は各動物の通常の餌やり処理に従います。クリエイティブでは通常どおり消費しません。
- 子供、繁殖クールダウン中、すでに繁殖モードの動物は範囲餌やりの対象外です。
- 未懐きのペットや馬は範囲対象外です。懐いた動物でも、回復などが繁殖より優先される場合があります。
- Shiftを押しながら右クリックすると通常の単体操作になります。
- 範囲内の動物には柵や壁越しにも届きます。

## 設定
Mod Menu の Feed Assist 設定で、有効・無効と半径（2～10ブロック）を変更できます。
config/feed-assist.json でも設定できます。ファイルを直接編集する場合はゲーム／サーバーを停止してから変更してください。

    {
      "feedRange": 10,
      "enabled": true
    }

マルチプレイではサーバーの設定が優先されます。クライアントの設定画面ではサーバー設定を変更できません。

## ビルド
Windows: .\gradlew.bat build
生成先: build/libs/feed-assist-mc26.1.2-1.0.0.jar

## ゲーム内の確認項目
- 大人の牛・羊を複数置き、小麦で1匹を右クリックすると範囲内にハートが出て、頭数分の餌が減る。
- 子供、繁殖済み、範囲外、餌の違う動物に余分な餌を使わない。
- 餌が1個だけならクリックした1匹だけに与え、空になった手で周囲を操作しない。
- オフハンド、クリエイティブ、Shiftによる単体操作、設定OFFを確認する。
- 半径設定を変更し、保存後・再起動後とも反映されることを確認する。
- 専用サーバーに導入し、クライアントにMODがなくても範囲餌やりできることを確認する。
